# LUMORA — Modern Essentials

LUMORA is a modern full-stack e-commerce product catalog built with React, Vite, Node.js and Express.

The project focuses on a clean shopping experience with product discovery, search, filtering, sorting, wishlist management and a shopping bag.

## 🌐 Live Demo

**Frontend:**  
https://lumora-six-omega.vercel.app/

**Backend API:**  
https://lumora-api-3qvp.onrender.com/

**GitHub Repository:**  
https://github.com/kritidey42-bot/LUMORA

---

## ✨ Features

- Modern responsive e-commerce interface
- Product catalog
- Product search
- Category filtering
- Price sorting
- Add to Bag functionality
- Remove products from Bag
- Shopping Bag subtotal
- Wishlist functionality
- React client-side routing
- REST API for product data
- Responsive navigation
- Collections page
- About page
- Newsletter section
- Production deployment
- Environment-based API configuration
